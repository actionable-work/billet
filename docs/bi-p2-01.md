## Acceptance evidence

Rust fixtures retain all BI-P1 checks: independent canonical evaluations, portable
golden/defaults/argv preservation, 31 invalid definitions, seven value-free field
reports, reference-only secret artifacts, five executable build failures and full
transitive NAR identities. Compiled CLI acceptance now exercises six actions.

OCI acceptance independently verifies native nix2container output, addressed blob
hashes/sizes, decompressed DiffIDs, exact execution parameters, backend revision
and every file/symlink/mode in the 18-path runtime fixture. The image contains
separate init/probe/config dependencies and no unrelated builder paths. Metadata
is byte-identical to the canonical manifest/descriptor. Two independent upstream
exports reproduce the OCI layout and blob bytes. Root-prefixed backend tar paths
are interpreted within the image; parent traversal and unexpected contents fail.

Preflight fixtures prove complete required-capability rejection, field-path
mapping, unknown capabilities, image-system/user rejection and a trap package
that must never be built. Defaults are not waived to produce configuration.

The hello export's image manifest digest is
`sha256:e9a8bab0fc38558de822e2b23751fb976f39554ce7a434bb47704721024da8e1`.
Its Billet manifest digest remains
`sha256:ccd2f7bebe0716db85cf6c7c9645a587df9a3588d0dea0adca862b9c2db6634e`.
Provenance binds both identities, the descriptor digest, system and backend pin.

## Remaining gate

This closes BI-P2.01, not all of BI-P2. Only x86_64-linux has execution evidence;
ARM64 packaging is represented but not runtime-qualified. The next slice must
implement and test a bounded Compose lifecycle adapter: initialization before each
launch, startup/readiness/liveness, durable retries, complete-tree cleanup and
intentional-stop suppression. Required rollout/rollback, runtime secrets,
networking, resources and storage need their own preserved semantics or explicit
rejection. A default service cannot silently opt out of these requirements.

[Handoffs](handoffs.md) retain the open interface questions. Adjacent repositories
were not modified. BI-P1 is committed; this continuation is left reviewable as a
separate working-copy changeset, with no push.
